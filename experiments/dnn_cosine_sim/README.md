# DNN Cosine Similarity Simulation

## Goal
The goal of this experiment is to investigate whether a Deep Neural Network (DNN) can be trained to simulate the behavior of cosine similarity.

## Hypothesis
A sufficiently deep neural network should be able to approximate the non-linear relationship captured by cosine similarity between two vectors.

## Experiment Setup
- **Input**: Pairs of vectors.
- **Target**: Cosine similarity score between the pairs.
- **Model**: A Multi-Layer Perceptron (MLP) or similar architecture.
